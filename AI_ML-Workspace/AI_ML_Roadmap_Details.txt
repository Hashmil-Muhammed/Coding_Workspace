    * Filtering Toolkit: BETWEEN, IN, LIKE ('A%'), IS NULL / IS NOT NULL, NOT, COALESCE(x, 0)

   B) Joins, Aggregations & Dialect Differences:
    * SQL Joins: INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN, CROSS JOIN, SELF JOIN
    * Anti-Join Pattern: LEFT JOIN ... WHERE right.id IS NULL (identifying unmatched records)
    * Aggregations: COUNT(*), COUNT(col), COUNT(DISTINCT col), SUM, AVG, MIN, MAX; GROUP BY rule
    * Dialect Differences: MySQL/Postgres (LIMIT 10, CURRENT_DATE, CONCAT, COALESCE) vs SQL Server (TOP 10, GETDATE(), +, ISNULL)

    * Date Functions: CURRENT_DATE, DATE_TRUNC, EXTRACT, DATEDIFF, DATE_ADD

    * Conditional Logic: CASE WHEN condition THEN result ELSE default END
   C) Advanced SQL: CTEs, Window Functions & Retention:
    * Common Table Expressions (CTEs): WITH clause, chained CTEs, correlated subqueries vs joins, EXISTS vs IN
    * Set Operations: UNION (deduplicates) vs UNION ALL (faster, keeps duplicates), INTERSECT, EXCEPT / MINUS
    * Window Functions Syntax: fn() OVER (PARTITION BY ... ORDER BY ... ROWS BETWEEN ...)
    * Ranking Functions: ROW_NUMBER() (unique 1,2,3), RANK() (gap ties 1,1,3), DENSE_RANK() (no gap ties 1,1,2)
    * Offset & Aggregate Windows: LAG() / LEAD() (previous/next row), SUM() OVER (running total), AVG() OVER (moving average)
    * Distribution Windows: NTILE(4) (quartiles), FIRST_VALUE() / LAST_VALUE()
    * Date Patterns & Retention: Rolling 30 days, Month-on-Month growth, Day 0 vs Day 7 retention cohort queries

   D) SQL Performance, Pitfalls & Interview Query Patterns:
    * Performance Tuning: Specific column selection (no SELECT *), early filtering, joining on indexed keys
    * Query Plan Analysis: EXPLAIN / EXPLAIN ANALYZE, sargable queries (avoiding functions on indexed filter columns)
    * Common SQL Pitfalls: Join Fan-Out (duplicate inflation of SUM; check grain), NOT IN with NULLs (use NOT EXISTS)
    * Common SQL Pitfalls: Integer division truncation, timestamp comparison boundaries (>= and <), DISTINCT hiding bad joins
    * Interview Pattern: Nth Highest Salary (DENSE_RANK() or subquery with LIMIT/OFFSET)
    * Interview Pattern: Top N Per Department using DENSE_RANK() OVER (PARTITION BY dept ORDER BY salary DESC)

    * Metric Principles: One owner, one definition, one source; Pair metrics (growth + quality e.g. signups + retention)
    * Sales & Marketing KPIs: Conversion Rate (conversions/visitors), CAC (marketing+sales cost / new customers)

    * Product & Customer KPIs: DAU/MAU Stickiness, Retention Rate (% active after N days), Churn Rate, NPS, CSAT

    * Operations & HR Metrics: On-time Delivery Rate, Inventory Turns (COGS / avg inventory), Defect Rate, Attrition Rate, Time to Hire

    * Step 1: Confirm the drop is real (verify data pipeline, rule out tracking bugs or logging failures)

    * Step 4: Check external events (pricing changes, website/payment outage, seasonality, competitor campaigns)
    * Step 5: Recommend action & estimate financial/operational impact for leadership
